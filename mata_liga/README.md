# МАТА Лига

Беговое приложение экосистемы МАТА, в котором каждая пробежка попадает сразу в
несколько зачётов: абсолютный, личный рекорд, постоянство, своя лига по возрасту
и полу, усилие по пульсу, клубный. Бегун сам выбирает, какие зачёты ему важны.

Отдельное приложение, а не ветка «Квартала»: «Квартал» остаётся стабильным у
тестировщиков, пока здесь идёт перестройка игры. Ставится на телефон рядом с ним
(`ru.mata.liga` против `ru.mata.kvartal`).

- Что строим: `../docs/LEAGUE_PLAN.md`
- Зачем: `../docs/STRATEGY_KVARTAL.md`
- Часы и партнёрские заявки: `../docs/WEARABLES_PARTNERS.md`
- Правила работы: `CLAUDE.md`

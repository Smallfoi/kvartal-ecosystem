# Штамп МАТА — система наград Квартала

**Утверждено владельцем 2026-09-01** (9 итераций). Живой дизайн-документ:
[`shtamp-mata.html`](shtamp-mata.html) — открыть в браузере, всё рендерится
и анимируется на месте (чистый SVG + CSS/SMIL, без зависимостей).
Артефакт для просмотра/шаринга: https://claude.ai/code/artifact/812897a7-bbb5-4c80-9714-965c2eb63497

## Система в одном абзаце

44 награды, один шестигранный штамп — форма квартала карты (вершиной вверх, R=50).
**Кант держит категорию** (полировка · насечка · рифление · витой трос · бисер),
**металл держит ранг** (сталь → бронза → серебро → золото → иридий),
**эмблема держит награду**. Эмаль (лайм/голубой/лёд) — только иридий и отдельные
лимитированные. Категории: Ритм 11 · Территория 9 · Дистанция 11 · Сезон и лига 7 ·
Лимитированные 6.

## Правила, выстраданные итерациями (нарушение = откат владельцем)

1. **Никаких наложений** — ни в текстах, ни в деталях. Все зазоры считать геометрией
   (шестиугольник сужается к вершинам быстрее, чем кажется). Надписи — только по
   круговым дугам (на шестиугольной дорожке буквы сталкиваются в углах).
2. **Никакой «паутины»** — фон поля только азурирование (концентрические круги без
   лучей), кольца не заходят в пояс надписей.
3. **Эмблема — иллюстрация, не пиктограмма.** Многослойная художественная чеканка
   почти на всё поле; счётчики (серии/недели/кратности) — строгая гравюра.
4. **Цифры и год — на графитовой плашке** с металлическим кантом; в эмалевом канте
   под плашку вырезается окно (mask), плашка не ложится на эмаль.
5. **У каждой медали своя анимация самой эмблемы** — общий крутящийся фон запрещён
   как «ленивый». Щит принимает стрелу, перехват делает один оборот и замирает,
   район смагничивается, разметка бежит, солнце восходит, крылья взмахивают,
   окна загораются, снег идёт, лучи ордена вращаются. При появлении — «чеканка»:
   эмблема вбивается, плашка выезжает снизу, дуга проявляется.
   Пульсаций/ударных волн нет (D-46 про знак Квартала соблюдён по духу).
6. **Медали именные**: реверс с личной гравировкой (пик зон, время, дата, город),
   тап — чистый 3D-переворот без подскока. Город лимитированных — из GPS пробежки.
7. Палитра и шрифты — только из системы Квартала: `app_colors.dart`
   (лайм #DFF45F, голубой #57BCD8, графит #20252B), Unbounded + Manrope.

## Как обновлять

Файл самодостаточен: медали генерируются JS-функцией `renderMedal()` из списка
`SERIES` (там же требования выдачи), эмблемы — объект `EMB`, металлы — `METALS`.
Добавить медаль = добавить элемент в `SERIES`; новый год чекана = поле `year`.
После правок — перепубликовать артефакт по тому же URL.

## План на 2027

- Год на плашке лимитированных — **новый чекан каждый год** (медаль-2027 ≠ 2026);
  серию 2027 строить на этом же штампе, меняя эмблемы/приметы событий.
- Внедрение в приложение: SVG-спрайт в `assets/medals/` + flutter_svg; анимации
  переложить на Flutter (см. `flutter-animations`), на размерах ≤44 px — статика;
  закрытое состояние — ColorFilter поверх того же ассета, второй файл не нужен.

## Технические грабли SVG (подробнее в docs/PITFALLS.md)

textPath по многоугольнику с углами; CSS transform-box/transform-origin на вложенных
SVG-группах (лучи уезжали — лечится SMIL `animateTransform`); дуга `A` с радиусом
меньше половины хорды молча раздувается (луна становилась кругом — серп собран маской);
CSS-анимация transform затирает атрибут `transform` (нужны вложенные обёртки).

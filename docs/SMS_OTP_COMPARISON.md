# Провайдер OTP (код входа) — анализ и выбор

Единый источник правды по доставке кодов подтверждения (вход/регистрация/сброс пароля)
для всей экосистемы МАТА (Квартал, Store, сайт). Сейчас во всех продуктах — dev-код `1234`;
этот документ — про переход на реальную доставку.

Дата анализа: **2026-08-24**. Актуальность цен проверять перед оплатой.

## Цель
Отправлять одноразовый код пользователю по номеру телефона (+7) максимально **дёшево**,
**надёжно** и **универсально**. Экраны OTP (эталонная анимация V5, см. память
`otp-verification-animation-standard`) не меняются — меняется только источник кода на бэкенде.

## РЕШЕНИЕ: SIGMA messaging (D-50)
**Стратегия владельца:** звонок (flashcall) — основной канал, SMS — резерв. ИП есть.

Почему SIGMA:
- **FlashCall (0,39 ₽) + SMS-резерв — одна платформа, одна интеграция.** Не клеим двух провайдеров.
- **Каскад Smart Route** — нативно «звонок → не дошёл → SMS» (по заявлению до 70% экономии бюджета).
- **Задел на будущее:** там же Telegram/WhatsApp/Viber — можно добавить ещё более дешёвые каналы без новой интеграции.
- Протоколы HTTP/XML/**SMPP**, SDK (PHP/Python3/Java/C#/JS). Работает с ИП.

Альтернатива, если приоритет — максимальная надёжность звонка: **МТС Exolve** (звонок через
оператора МТС, дороже ~1,9 ₽). Самый дешёвый звонок — Plusofon (0,19 ₽), но у SIGMA удобнее
собраны резерв и мессенджеры в один API.

## Архитектура на бэкенде
- Абстракция «канал OTP» в auth-флоу (сейчас там dev-код `1234`).
- Порядок: **FlashCall → (не доставлено/нажали «не пришло») → SMS**. Позже — Telegram первым шагом.
- FlashCall: код — это **последние 4 цифры звонящего номера**, их определяет провайдер и
  возвращает нам в ответе API; бэкенд хранит код в сессии верификации и сверяет ввод
  пользователя (в отличие от SMS, где код генерируем мы). Точный контракт — из кабинета SIGMA.
- Возможен нативный каскад SIGMA (Smart Route) — тогда фолбэк на стороне провайдера.
- Экраны/анимация OTP не меняются; добавляется подпись «код придёт звонком» + кнопка «прислать SMS».

## Оценка стоимости (грубо)
При 1000 входов/мес: ~390 ₽ звонком + SMS только для тех, кому звонок не дошёл (~9 ₽ × доля).
Даже с резервом — считанные сотни рублей в месяц на старте.

## Что нужно от владельца (ИП)
1. Регистрация на **sigmasms.ru** (на ИП), пополнение баланса.
2. Получить **API-токен** (для интеграции; передать Claude, как секрет).
3. Подключить **FlashCall** и **SMS** в кабинете; для SMS — **зарегистрировать имя отправителя**
   (1–2 недели — начать сразу; для flashcall имя не требуется).
4. Дать доступ к разделу документации API (endpoint отправки, формат, статусы) или прислать
   ключевые детали — по ним Claude сделает интеграцию и живую проверку на телефоне.

## Статус
Провайдер выбран (SIGMA, D-50). Интеграция — после создания аккаунта и получения токена.
